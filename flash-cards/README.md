These flashcard decks can be downloaded from GitHub and imported into Anki for study and review.

1. Download the desired `.apkg` file from this repository.
2. Open Anki.
3. Select **File → Import**.
4. Choose the downloaded `.apkg` file.
5. Select **Open** to import the deck.

## Why Anki?
Anki is a flashcard application based on two well-established learning principles:
> **Active Recall**
>
> The process of retrieving information from memory rather than simply rereading notes. Every flashcard requires you to recall an answer before revealing it, strengthening memory retention.

> **Spaced Repetition**
>
> Information is reviewed at increasing intervals just before it is likely to be forgotten, improving long-term retention while reducing unnecessary review.
